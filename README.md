# Maya Chen Portfolio

A lightweight personal portfolio built with HTML, CSS, and JavaScript.

## Run locally

Because this is a static site, open `index.html` directly in a browser or serve the folder with any static file server.

## Deploy with GitHub Actions

1. Create a GitHub repository and push this project to the `main` branch.
2. In the repository, open **Settings > Pages** and set **Source** to **GitHub Actions**.
3. Push a change. The workflow in `.github/workflows/deploy.yml` will publish the site automatically.

Replace the sample name, email, social links, project content, and `resume.txt` with your own details before publishing.
